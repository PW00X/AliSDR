# AliSDR 1.2.0

- Includes name-only recording filenames for known channels, with frequency
  preserved in embedded WAV/MP3 metadata. Unknown channels keep frequency-based
  filenames. Existing frequency-based recordings remain supported.
- Settings → Recording → Rename existing recordings processes the existing
  library in the background and shows progress, renamed/skipped/failed counts
  and error details. Audio, transcripts, favourites and quality results are
  retained. Busy recordings and filename conflicts are skipped.
- ZIP downloads spanning multiple frequencies or channels now use separate
  folders. Named channels use their channel name; unnamed frequencies use
  folders such as **131.000 MHz**. A single-channel selection stays at the ZIP
  root. Names are made safe for extraction, and conflicts are disambiguated so
  recordings cannot overwrite one another.

Update the receiver with the source installer:

```sh
curl -fsSL https://raw.githubusercontent.com/PW00X/AliSDR/master/packaging/install.sh | bash
```

Reload the web client after updating. Remote workers must also be updated to
read the name-only recording format. The portable Windows worker is attached
to this release:

[Download AliSDR Worker for Windows x64](https://github.com/PW00X/AliSDR/releases/download/v1.2.0/AliSDR-Worker-Windows-x64.zip).
Extract it and run **Start AliSDR Worker.cmd**. Python is included; install the
transcription engine through the server's Add-ons page.
