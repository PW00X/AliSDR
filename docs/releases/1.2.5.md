# AliSDR 1.2.5

- FM and DAB favourites show the latest confirmed track and its age in seconds. New track text must stay stable for three seconds. A repeat on the same station within a rolling 30-minute window leaves the favourite and play history unchanged.
- DAB track monitoring is enabled by default. While the selected station plays, the monitor checks other services on the same ensemble and advances as soon as it recognizes or confirms a title.
- Music statistics group tracks across stations and show up to 50 recent plays per track. Statistics tables support column sorting.
- Gain changes apply to the tuned receiver while listening. The web interface uses a 24-hour clock.
- Added decoding support for clear-mode TETRA.
