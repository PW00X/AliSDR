# AliSDR 1.1.5

- Enlarged station artwork to 120 × 120 pixels. Moved the Station information
  heading beside the tuner status, aligned right, and placed modulation and
  frequency/channel controls below Tune/Scan and above the signal meter for a
  more compact tuner card.
- Placed other detected Scan signals beside the active frequency name to
  reduce the Scan tuner card height.
- Moved Auto-record and Boost into the Scan button area alongside Record and
  Add to Channels, removing the separate settings row.
- Combined Tune and Scan on the Listen page, with receiver gain shared between
  both modes and a Listen button in Tune. Listen opens in Scan while scanning
  and defaults to Tune when the receiver is idle.
- Fixed application of receiver gain while scanning and restored the Scan gain
  controls. The default server port is now 2424.
- Improved Android live playback with native audio streaming, media controls,
  reconnection and a buffer that keeps decoder bursts contiguous. This includes
  the correction for stuttering introduced by padding between valid DAB bursts.
- Applied the transcription idle-only setting to the server, leaving remote
  workers free to transcribe while the receiver is active. DAB transcription
  pauses now respect the selected setting.
- Added a portable Windows transcription worker and fixed the missing `os`
  import when launching the Python worker.
- Fixed All recordings to respect the selected sidebar sort, including
  Frequency (A–Z), and order recordings oldest first by default.
- FM station discovery shows stations with decoded RDS names by default, with
  a toggle to include unnamed stations. The tuner status badge now says Tuned.

Update an existing installation with the source installer:

```sh
curl -fsSL https://raw.githubusercontent.com/PW00X/AliSDR/master/packaging/install.sh | bash
```

Reload the web client after updating. Android playback has been tested in
Chromium with decoder bursts and paused page JavaScript; playback with the
screen off still requires verification on an Android device.
