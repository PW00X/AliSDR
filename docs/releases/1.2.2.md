# AliSDR 1.2.2

- Messages shows VDL2 ACARS text and other data frames by default. New frames retain decoded protocol details. The All frames filter includes link acknowledgements.
- Show more messages expands the list. Clear list hides the expanded history on this browser while new arrivals remain visible. Show them restores hidden messages.
- USB Airspy receivers support VDL2. Tune and Scan can take the receiver back from VDL2. Successful VDL2 decodes suppress the corresponding automatic audio recording.
- ACARS and VDL2 can share an idle receiver. The ACARS decoder now recovers the differential bit encoding used on air.

Update the headless receiver with the source installer:

```sh
curl -fsSL https://raw.githubusercontent.com/PW00X/AliSDR/master/packaging/install.sh | bash
```

The portable Windows transcription worker is attached as **AliSDR-Worker-Windows-x64.zip**.
